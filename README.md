# Niri_Dots_1.0
A small modification to make a shell of niri with a small use of resources.

I use arch with niri, And please if you see mistakes or something in this git please tell me i am new making my own git and i am not an english native speaker so that.

Well i did this repository to share my niri dotfiles:
what did i bring in this dots?:
i add an automatic random generated wallpaper of fractals
my waybar with indicators of apps.
my rofi a little minimalist but i like it.
and my niri config that suits me.

you must need the next packages:
rofi-wayland
waybar
niri
alacritty
thunar
swaybg

and also you must create a virtual environment with pyfracgen
you also need to check de waybar-niri-workspace-enhanced i use his rust code for the waybar

## Créditos y Herramientas externas
Mis dotfiles utilizan y hacen referencia a los siguientes proyectos de código abierto:

* [pyfracgen](https://github.com) (Ryther Anderson) - Usado en scripts de Python para generación de arte fractal.
* [waybar-niri-workspaces-enhanced](https://github.com/justbuchanan/waybar-niri-workspaces-enhanced) (JustBuchanan) - Módulo mejorado de espacios de trabajo para Waybar en el compositor Niri.
